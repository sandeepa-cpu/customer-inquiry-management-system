# CIMS frontend

React + Vite client for the Customer Inquiry Management System.

From this directory:

1. Copy `.env.example` to `.env` if needed. Default `VITE_API_URL` is `http://localhost:5000`.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:5173`.
4. Run `npm test` for Vitest + React Testing Library checks (API calls are mocked).
5. Run `npm run build` for a production build.

Keep the Express API running on port 5000 for local use. See the repository README for stack, routes, and backend setup.
